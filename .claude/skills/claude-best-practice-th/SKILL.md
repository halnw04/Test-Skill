# คู่มือใช้ Claude Code ให้ได้ผล (ภาษาไทย)

เนื้อหาเรียบเรียงจาก [shanraisshan/claude-code-best-practice](https://github.com/shanraisshan/claude-code-best-practice) (MIT License) และเอกสารทางการ https://code.claude.com/docs

## วิธีใช้สกิลนี้
- **ผู้ใช้ถามหัวข้อใด**: ตอบจากส่วนที่ตรงกัน เป็นภาษาไทยง่าย ๆ พร้อมตัวอย่าง อธิบายศัพท์เทคนิคเมื่อใช้ครั้งแรก
- **ผู้ใช้ขอให้สร้างหรือตรวจสกิล**: ใช้ [references/skill-checklist.md](references/skill-checklist.md)
- **ผู้ใช้ขอเคล็ดลับทั้งหมด**: เปิด [references/tips-th.md](references/tips-th.md)
- **ข้อมูลอาจล้าสมัย**: ฟีเจอร์ของ Claude Code เปลี่ยนเร็ว ถ้าผู้ใช้ถามรายละเอียดคำสั่งหรือการตั้งค่า ให้ตรวจกับเอกสารทางการก่อนตอบ

## 7 หลักใหญ่ (สรุปสั้น)
1. **วางแผนก่อนลงมือ**: งานใหญ่ให้เริ่มด้วย Plan mode หรือให้ Claude สัมภาษณ์เราด้วยคำถามก่อน แล้วค่อยเริ่มทำ
2. **ให้ Claude มีวิธีตรวจงานตัวเอง**: เช่น รันเทส เปิดแอปดู หรือสั่งว่า "พิสูจน์ให้ดูว่าใช้ได้จริง" งานจะดีขึ้นมาก
3. **ดูแลบริบท (context)**: บริบทคือความจำระยะสั้นของการคุยครั้งนั้น ถ้าใช้เกิน 40-60% คุณภาพเริ่มตก งานใหม่ให้เปิดเซสชันใหม่ และใช้ `/compact` พร้อมบอกว่าจะเก็บอะไรไว้
4. **CLAUDE.md สั้นและคม**: ไม่เกิน 200 บรรทัด ใส่คำสั่งรัน/เทส กติกาโปรเจกต์ และสิ่งที่ Claude มักทำพลาด
5. **งานที่ทำเกินวันละครั้ง ให้ทำเป็นสกิลหรือคำสั่ง**: เช่น `/รายงาน` หรือ `/สรุป`
6. **ใช้ Subagent แบ่งงาน**: งานค้นหรืออ่านไฟล์เยอะ ๆ ให้ส่งต่อ subagent บริบทหลักจะได้ไม่รก
7. **ใช้การตั้งค่าแทนคำขอร้อง**: กติกาที่ต้องเป็นแบบนั้นทุกครั้ง (สิทธิ์, รูปแบบ commit) ให้ใส่ใน `settings.json` หรือ Hook จะได้ผลแน่นอนกว่าเขียนขอไว้ใน CLAUDE.md

## ส่วนประกอบของ Claude Code (อธิบายง่าย ๆ)
| ส่วน | คืออะไร | เก็บไว้ที่ |
|---|---|---|
| **CLAUDE.md** | โน้ตประจำโปรเจกต์ที่ Claude อ่านทุกครั้ง | รากโปรเจกต์ หรือ `~/.claude/CLAUDE.md` (ใช้ทุกโปรเจกต์) |
| **Rules** | CLAUDE.md ย่อย แยกตามหัวข้อ ตั้งให้โหลดเฉพาะเมื่อแตะไฟล์ที่เกี่ยวข้องได้ | `.claude/rules/*.md` |
| **Skill** | คู่มือเฉพาะงาน + สคริปต์ Claude จะโหลดเมื่องานตรงกับคำอธิบาย | `.claude/skills/<ชื่อ>/SKILL.md` |
| **Command** | คำสั่งลัด `/ชื่อ` (ปัจจุบันรวมอยู่ในระบบสกิลแล้ว) | `.claude/commands/<ชื่อ>.md` |
| **Subagent** | ผู้ช่วยแยก มีบริบทของตัวเอง ทำงานเสร็จแล้วส่งแค่ผลสรุปกลับ | `.claude/agents/<ชื่อ>.md` |
| **Hook** | สคริปต์ที่รันอัตโนมัติตามเหตุการณ์ เช่น หลังแก้ไฟล์ | `.claude/settings.json` |
| **MCP** | ปลั๊กเชื่อม Claude กับบริการภายนอก เช่น เบราว์เซอร์ หรือฐานข้อมูล | `.mcp.json` |
| **settings.json** | สิทธิ์ (อนุญาต/ห้าม/ถามก่อน), โมเดล, ตัวแปรระบบ | `.claude/settings.json` |

## การโหลด CLAUDE.md ในโปรเจกต์ใหญ่
- **โฟลเดอร์แม่ (ขึ้นไปข้างบน)**: โหลดทันทีตอนเริ่ม
- **โฟลเดอร์ลูก (ลงไปข้างล่าง)**: โหลดเมื่อ Claude เข้าไปอ่านไฟล์ในโฟลเดอร์นั้น
- **โฟลเดอร์พี่น้อง (ข้าง ๆ)**: ไม่โหลด
- **CLAUDE.local.md**: ไว้เก็บค่าส่วนตัว ควรใส่ไว้ใน `.gitignore`

## ⚠️ ข้อควรระวังเรื่องความปลอดภัย
- **อย่า copy โฟลเดอร์ `.claude` ของคนอื่นมาทั้งก้อน**: บาง repo ตั้งสิทธิ์ `Bash(*)` หรือ `Edit(*)` ซึ่งให้ Claude ทำได้ทุกอย่างโดยไม่ถาม
- **อ่านสคริปต์และ Hook ก่อนติดตั้งเสมอ**: เพราะมันจะรันบนเครื่องของคุณจริง
- **อยากลดการถามสิทธิ์บ่อย ๆ**: ใช้สิทธิ์แบบเจาะจง เช่น `Bash(npm run *)` หรือใช้ auto mode แทนการปิดการถามทั้งหมด
