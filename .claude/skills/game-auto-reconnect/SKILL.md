# ตัวเฝ้าเกม: หลุดแล้วต่อใหม่อัตโนมัติ

## ขอบเขต
**ทำ:** เฝ้าหน้าจอ → เจอหลุด → ทำขั้นตอนกู้คืนที่ผู้ใช้กำหนด (ล็อกอิน/เลือกเซิร์ฟ/ตัวละคร/เปิดบอทของเกมเอง)
**ไม่ทำ:** เล่นเกมแทน, ฟาร์ม/กดสกิล/เดินแทนบอทของเกม, แก้ไฟล์หรือหน่วยความจำเกม, หลบระบบกันโกง (สุ่มเมาส์ให้เหมือนคน, ปลอมเครื่อง ฯลฯ) ถ้าผู้ใช้ขอส่วนนี้ให้ปฏิเสธและอธิบายเหตุผลสั้น ๆ

## ไฟล์
- `scripts/reconnect_bot.py`: ตัวหลัก (คำสั่ง `run`, `run-all`, `snap`, `check`, `crop`)
- `examples/yulgang/`: config + คู่มือติดตั้งภาษาไทยสำหรับ Yulgang 2 ไอดี (ส่งผู้ใช้ไปอ่าน README ในนั้น)
- `examples/mock-game/`: เกมจำลองไว้ทดสอบ (`index.html?canvaslogin=1&dc=วินาที`) + config ตัวอย่างที่ทดสอบผ่านแล้ว
- `requirements.txt`: `pip install -r requirements.txt`

## หลักการทำงาน
1. **ตรวจทุก `check_interval` วินาที:** ถ้าเข้าเงื่อนไขอย่างใดอย่างหนึ่งใน `disconnect_when` หรือไม่เห็น `healthy_when` ติดกัน `unhealthy_after` รอบ ให้ถือว่าหลุด
2. **กู้คืน:** ทำ `recovery_steps` ตามลำดับ แล้วตรวจซ้ำอีกรอบ ถ้าไม่ผ่านจะรอแล้วลองใหม่ เวลารอจะเพิ่มเป็น 2 เท่าทุกครั้ง
3. **ลองไม่สำเร็จครบ `max_attempts_in_a_row` ครั้ง:** หยุดทำงาน และเก็บภาพหน้าจอไว้ใน `logs/`
4. **หลายไอดี:** ใช้ `accounts:` ใน config และคำสั่ง `run-all` แต่ละไอดีจะได้ Chrome คนละโปรไฟล์ log คนละไฟล์ และหน้าต่างคนละตำแหน่ง ใช้ `{{ชื่อ}}` อ้างค่าของไอดีนั้นใน steps เช่น `{{user}}` หรือ `{{char_image}}`

## ขั้นตอนที่ใช้ได้ (recovery_steps)
`goto` · `reload` · `wait` · `wait_image` · `click_image` (+`offset: [x,y]`) · `click_xy` · `click_text` · `click_selector` · `fill` (ฟอร์ม HTML) · `type` (พิมพ์ลงช่องที่คลิกไว้) · `press` (ปุ่มลัด เช่น `F10`)
ตัวเลือกเสริมทุกขั้น: `name`, `timeout`, `after` (รอหลังทำ), `optional: true`, `skip_if_image`

## เมื่อผู้ใช้ส่งภาพหน้าจอจาก `shots/` มา
1. เปิดดูภาพ หาตำแหน่งปุ่มหรือข้อความที่ต้องใช้
2. ตัดภาพด้วย `reconnect_bot.py crop ภาพ.png x y กว้าง สูง templates/ชื่อ.png`
3. แก้ config ให้ตรงกับชื่อไฟล์ และแก้ `offset` ของช่องกรอก (ระยะจากกึ่งกลางป้ายถึงกึ่งกลางช่อง)
4. ให้ผู้ใช้รัน `check` เพื่อยืนยันผล

## กติกาสำคัญ (Gotchas)
- **ช่องกรอกในเกมที่วาดบนจอ (canvas/WebGL):** ใช้ `fill` ไม่ได้ ต้องใช้ `click_image` ที่ป้าย (ID/PASSWORD) + `offset` แล้วตามด้วย `type` อย่าใช้รูปของช่องกรอกเปล่า ๆ เพราะช่อง ID กับ PASSWORD หน้าตาเหมือนกัน จะคลิกผิดช่อง
- **ปุ่มที่รูปร่างเดียวกันแต่ต่างสี (เช่น ออโต้ปิด/เปิด):** การเทียบรูปร่างแยกไม่ออก (คะแนนประมาณ 1.00 ทั้งคู่) สคริปต์จึงตรวจสีซ้ำด้วย `color_tolerance` ทุกครั้ง และขั้นเปิดบอทต้องมี `skip_if_image: bot_on.png` เสมอ ไม่อย่างนั้นอาจกดปิดบอทที่เปิดอยู่แล้ว
- **ปุ่มที่ถูกหน้าต่างอื่นทับจนมืด:** ยังได้คะแนนรูปร่างสูง แต่จะไม่ผ่านการตรวจสี ถ้าเจออาการ "หาไม่เจอทั้งที่เห็นปุ่ม" ให้ดูว่ามีอะไรทับปุ่มอยู่หรือไม่
- **ต้องตัดรูปต้นแบบจากภาพที่ได้จาก `snap` เท่านั้น:** ห้ามใช้ภาพจาก Snipping Tool เพราะการซูมของ Windows ทำให้ขนาดไม่ตรง และ viewport ต้องเท่าเดิมตลอด
- **รหัสผ่าน:** ใช้ `${ENV}` (ตั้งด้วย `setx` บน Windows) ห้ามเขียนลงใน config หรือ commit ขึ้น git และต้องเป็นภาษาอังกฤษหรือตัวเลข เพราะ `type` ส่งการกดแป้นแบบภาษาอังกฤษ
- **ป้ายช่องกรอก:** ป้าย `login_label_id.png` ใช้เป็นสัญญาณ "อยู่หน้าล็อกอิน" ใน `disconnect_when` ได้ด้วย
- **อย่าตั้ง `check_interval` ต่ำกว่า 5 หรือ `max_recoveries_per_hour` สูงเกินไป:** การล็อกอินถี่ ๆ อาจทำให้เซิร์ฟเวอร์บล็อกไอดี
- **การทดสอบ:** ทดสอบกับเกมจำลองแล้ว (2 ไอดี หลุดทุก 12 วินาที กู้คืนได้ครบทุกครั้ง) แต่ยังไม่ได้ทดสอบกับ Yulgang จริง เพราะต้องใช้รูปต้นแบบจากเครื่องของผู้ใช้ ห้ามบอกว่าใช้กับเกมจริงได้แน่นอน จนกว่าผู้ใช้จะยืนยันผล
