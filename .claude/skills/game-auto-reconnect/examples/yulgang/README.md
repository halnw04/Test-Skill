# ตั้งค่าตัวเฝ้าเกม Yulgang (2 ไอดี)

ใช้เวลาตั้งค่าครั้งแรกประมาณ 20-30 นาที หลังจากนั้นแค่ดับเบิลคลิก `start-yulgang.bat`

## 1. ติดตั้ง (ครั้งเดียว)
1. ดาวน์โหลด repo: เปิด https://github.com/halnw04/Test-Skill แล้วกดปุ่มเขียว **Code** → **Download ZIP** จากนั้นแตกไฟล์และเปลี่ยนชื่อโฟลเดอร์เป็น `C:\Test-Skill`
2. ติดตั้ง Python 3.11 ขึ้นไปจาก https://www.python.org/downloads/ ตอนติดตั้ง**ติ๊ก "Add python.exe to PATH"**
3. เปิด Command Prompt แล้วพิมพ์:
   ```
   cd C:\Test-Skill\.claude\skills\game-auto-reconnect
   pip install -r requirements.txt
   ```
   (ใช้ Google Chrome ที่มีอยู่ในเครื่อง ไม่ต้องดาวน์โหลดเบราว์เซอร์เพิ่ม)

## 2. ตั้งรหัสผ่าน (ครั้งเดียว ไม่ต้องเขียนรหัสลงไฟล์)
```
setx YG_USER1 "ไอดีที่1"
setx YG_PASS1 "รหัสที่1"
setx YG_USER2 "ไอดีที่2"
setx YG_PASS2 "รหัสที่2"
```
แล้ว**ปิด Command Prompt เปิดใหม่** (ค่าถึงจะมีผล)
ไอดีและรหัสต้องเป็นภาษาอังกฤษหรือตัวเลขเท่านั้น

## 3. เก็บรูปต้นแบบ (สำคัญที่สุด)
```
cd C:\Test-Skill\.claude\skills\game-auto-reconnect\examples\yulgang
python ..\..\scripts\reconnect_bot.py snap -c config.yaml --account 1
```
Chrome จะเปิดเกมขึ้นมา เล่นไปทีละหน้า แล้วกด **Enter** ที่หน้าต่างดำเพื่อเก็บภาพหน้าจอ (ไฟล์อยู่ในโฟลเดอร์ `shots`) ต้องเก็บทุกหน้าต่อไปนี้:

| หน้าจอ | ตัดรูปอะไร | ตั้งชื่อไฟล์ |
|---|---|---|
| หน้าล็อกอิน | คำว่า **ID** (สีทอง) | `login_label_id.png` |
| หน้าล็อกอิน | คำว่า **PASSWORD** | `login_label_password.png` |
| หน้าล็อกอิน | ปุ่ม **ตกลง** | `login_btn_ok.png` |
| หน้าเลือกเซิร์ฟ | ชื่อเซิร์ฟที่เล่น | `server.png` |
| หน้าเลือกตัวละคร | ตัวละครของไอดี 1 / ไอดี 2 | `char_id1.png`, `char_id2.png` |
| หน้าเลือกตัวละคร | ปุ่มเข้าเกม | `btn_enter_game.png` |
| ในเกม บอทปิด | ปุ่มออโต้ตอนปิด | `bot_off.png` |
| ในเกม บอทเปิด | ปุ่ม/ข้อความที่บอกว่าออโต้ทำงาน | `bot_on.png` |
| ตอนหลุด (ถ้าเจอ) | หน้าต่างแจ้งเตือน / ปุ่มตกลงของมัน | `dc_dialog.png`, `dc_ok.png` |

**วิธีตัดรูป:** เปิดภาพใน `shots` ด้วย **Paint** → ลากกรอบเฉพาะปุ่ม/ข้อความ → **Crop** → Save As PNG ลงโฟลเดอร์ `templates`

⚠️ ต้องตัดจากภาพใน `shots` เท่านั้น **ห้ามใช้ Snipping Tool / Print Screen** เพราะขนาดจะไม่ตรงกับที่สคริปต์เห็น

💡 ส่งภาพใน `shots` มาให้ Claude ช่วยตัดและแก้ config ให้ได้

## 4. ทดสอบรูปต้นแบบ
```
python ..\..\scripts\reconnect_bot.py check -c config.yaml --account 1
```
ไปที่หน้าจอที่ต้องการแล้วกด Enter สคริปต์จะบอกว่าเจอรูปไหน (✅) คะแนนเท่าไร ควรได้ 0.90 ขึ้นไป

## 5. เริ่มใช้งาน
ดับเบิลคลิก `start-yulgang.bat` (หรือ `python ..\..\scripts\reconnect_bot.py run-all -c config.yaml`)
- เปิด Chrome 2 หน้าต่าง ซ้าย = ไอดี 1 ขวา = ไอดี 2
- ดูประวัติได้ที่ `reconnect-1.log`, `reconnect-2.log`
- ถ้ากู้คืนไม่สำเร็จ จะเก็บภาพหน้าจอไว้ใน `logs` เพื่อดูว่าติดที่ขั้นไหน
- หยุด: กด Ctrl+C ในหน้าต่างดำ

## ข้อควรรู้
- ใช้หน้าต่าง Chrome ที่สคริปต์เปิดให้ ไม่ใช่ Chrome ปกติของคุณ (โปรไฟล์แยก ไม่ยุ่งกับบุ๊กมาร์กเดิม)
- **อย่าปรับขนาดหน้าต่าง/ซูมหน้าเว็บ** ระหว่างใช้งาน รูปต้นแบบจะไม่ตรง
- ย่อหน้าต่าง (minimize) ได้ แต่ถ้าเกมหยุดวาดภาพตอนย่อ ให้วางหน้าต่างไว้บนจอแทน
- ถ้าเกมอัปเดตหน้าตาปุ่ม ต้องเก็บรูปต้นแบบใหม่
- ตรวจกฎของเกมก่อนใช้ ว่าอนุญาตโปรแกรมช่วยล็อกอินอัตโนมัติหรือไม่
