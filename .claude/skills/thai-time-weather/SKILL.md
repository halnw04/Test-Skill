# เวลาและอากาศประเทศไทย

## เครื่องมือ
สคริปต์ `scripts/thai_weather.py` (อยู่ในโฟลเดอร์เดียวกับไฟล์นี้) ใช้แค่ Python มาตรฐาน ไม่ต้องติดตั้งอะไรเพิ่ม ข้อมูลอากาศมาจาก Open-Meteo ซึ่งใช้ฟรีและไม่ต้องสมัคร

```bash
python3 <โฟลเดอร์สกิล>/scripts/thai_weather.py              # เวลา + อากาศกรุงเทพฯ
python3 <โฟลเดอร์สกิล>/scripts/thai_weather.py เชียงใหม่      # ระบุจังหวัด
python3 <โฟลเดอร์สกิล>/scripts/thai_weather.py --time       # เวลาอย่างเดียว
python3 <โฟลเดอร์สกิล>/scripts/thai_weather.py --lat 13.36 --lon 100.98 --name "ออฟฟิศ"
```

## วิธีตอบ
- **ถามแค่เวลาหรือวันที่**: ใช้ `--time` แล้วตอบสั้น ๆ 1 บรรทัด
- **ถามเรื่องอากาศ**: แสดงผลจากสคริปต์ แล้วเพิ่มคำแนะนำ 1 บรรทัด เช่น
  - โอกาสฝนเกิน 50% → "พกร่มด้วยนะครับ"
  - UV 8 ขึ้นไป → "แดดแรง ควรทาครีมกันแดด"
  - รู้สึกเหมือน 40°C ขึ้นไป → "ร้อนจัด ดื่มน้ำบ่อย ๆ"
- **ไม่ระบุจังหวัด**: ใช้กรุงเทพฯ และบอกผู้ใช้ว่าเปลี่ยนจังหวัดได้

## กติกาสำคัญ (Gotchas)
- **ห้ามเดาอากาศ**: ถ้าสคริปต์ขึ้นว่า "ดึงข้อมูลอากาศไม่สำเร็จ" ให้บอกผู้ใช้ตรง ๆ และแนะนำให้เช็กกรมอุตุนิยมวิทยา (tmd.go.th)
- **เวลา**: ใช้เวลาจากสคริปต์เสมอ อย่าเดาจากความจำ
- **ชื่ออำเภอหรือสถานที่เล็ก**: ถ้าค้นไม่เจอ ให้ลองชื่อจังหวัด หรือใช้ `--lat/--lon`
- **ความแม่นยำ**: ข้อมูลเป็นค่าพยากรณ์จากแบบจำลอง สำหรับเตือนภัยหรือพายุ ให้แนะนำประกาศของกรมอุตุฯ
