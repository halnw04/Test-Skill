# รายงาน Excel อัตโนมัติ

เป้าหมาย: ส่งไฟล์ข้อมูลเข้ามา 1 ไฟล์ ได้ไฟล์รายงานที่เปิดใน Excel ได้ทันที พร้อมบทสรุปภาษาไทยที่บอกว่าข้อมูลหมายความว่าอะไร

## เครื่องมือ
สคริปต์ `scripts/make_report.py` (อยู่ในโฟลเดอร์เดียวกับไฟล์นี้) ทำงานหนักให้ทั้งหมด อย่าเขียนโค้ดสรุปข้อมูลขึ้นใหม่เองถ้าสคริปต์นี้ทำได้

```bash
# ครั้งแรก ถ้ายังไม่มีไลบรารี
pip install pandas openpyxl

# ให้สคริปต์เดาคอลัมน์ให้เอง
python <โฟลเดอร์สกิล>/scripts/make_report.py ข้อมูล.xlsx

# ระบุคอลัมน์เอง (แนะนำเมื่อรู้ชื่อคอลัมน์)
python <โฟลเดอร์สกิล>/scripts/make_report.py ข้อมูล.csv --group สาขา --value ยอดขาย --date วันที่ -o รายงาน.xlsx
```

ตัวเลือกอื่น: `--sheet ชื่อชีต` ใช้อ่านชีตที่ไม่ใช่ชีตแรก

**ผลลัพธ์**
1. ไฟล์ `<ชื่อเดิม>_รายงาน.xlsx` มีชีตดังนี้
   - **ภาพรวม:** จำนวนแถว แถวซ้ำ และยอดรวม
   - **คุณภาพข้อมูล:** ค่าว่างของแต่ละคอลัมน์
   - **สรุปตามกลุ่ม:** ยอดของแต่ละกลุ่ม พร้อมกราฟแท่ง
   - **รายเดือน:** ยอดแต่ละเดือน พร้อมกราฟเส้น
   - **ข้อมูลดิบ:** ข้อมูลต้นฉบับ
2. ข้อมูลสรุปรูปแบบ JSON แสดงบนหน้าจอ ใช้ข้อมูลนี้เขียนบทวิเคราะห์

## ขั้นตอนการทำงาน
1. เปิดดูหัวคอลัมน์และข้อมูล 5 แถวแรกก่อน เพื่อเลือก `--group` / `--value` / `--date` ที่เหมาะสม ถ้ามีหลายคอลัมน์ที่เป็นไปได้และเลือกผิดจะทำให้รายงานผิด ให้ถามผู้ใช้
2. รันสคริปต์
3. เขียนบทวิเคราะห์ภาษาไทยจาก JSON ตามแม่แบบด้านล่าง
4. ส่งไฟล์รายงานและบทวิเคราะห์ให้ผู้ใช้

## แม่แบบบทวิเคราะห์
```
## 📊 รายงาน: <ชื่อไฟล์>
**สรุปสั้น:** <1-2 ประโยค เช่น ยอดรวม 319,253 บาท จาก 300 รายการ "ชา" ขายดีที่สุด (37%)>

### ข้อค้นพบ
- <อันดับ 1-3 และสัดส่วน>
- <แนวโน้มรายเดือน: เดือนที่ขึ้น/ลงมากที่สุด เป็น %>

### ⚠️ ปัญหาข้อมูลที่พบ
- <ค่าว่าง, แถวซ้ำ, วันที่อ่านไม่ได้ (บอกจำนวน)>

### ข้อแนะนำ
- <สิ่งที่ควรดูต่อหรือทำต่อ 1-3 ข้อ>
```

## กติกาสำคัญ (Gotchas)
- **ตัวเลขทุกตัวในบทวิเคราะห์ต้องมาจาก JSON**: ห้ามคำนวณในหัวหรือปัดเลขเอง
- **ค่าว่าง**: สคริปต์ข้ามแถวที่ค่าว่างตอนรวมยอด ถ้ามีค่าว่างในคอลัมน์ตัวเลข ต้องแจ้งผู้ใช้เสมอ เพราะยอดจริงอาจสูงกว่านี้
- **วันที่แบบไทย**: สคริปต์อ่านวันที่แบบ วัน/เดือน/ปี และถ้าเจอปี พ.ศ. (เช่น 2569) จะแปลงเป็น ค.ศ. ให้อัตโนมัติ ถ้า JSON มี "หมายเหตุวันที่" ให้บอกผู้ใช้ด้วย
- **"วันที่อ่านไม่ได้" / "ตัวเลขอ่านไม่ได้" มากกว่า 0**: แปลว่ามีข้อมูลที่หายไปจากการสรุป ต้องแจ้งจำนวนให้ผู้ใช้ทราบ
- **CSV ภาษาไทยเป็นตัวอ่านไม่ออก**: สคริปต์ลอง UTF-8 และ TIS-620 ให้อัตโนมัติแล้ว ถ้ายังอ่านไม่ได้ ให้ผู้ใช้บันทึกไฟล์เป็น "CSV UTF-8"
- **ตัวเลขที่มีคอมมาหรือคำว่า "บาท"**: สคริปต์ล้างให้อัตโนมัติ
- **เดาคอลัมน์ผิด**: ดูค่า "คอลัมน์จัดกลุ่ม" / "คอลัมน์ตัวเลขหลัก" ใน JSON ถ้าไม่สมเหตุสมผล ให้รันใหม่โดยระบุคอลัมน์เอง
- **ห้ามแก้ไฟล์ต้นฉบับของผู้ใช้**: สคริปต์สร้างไฟล์ใหม่เสมอ
